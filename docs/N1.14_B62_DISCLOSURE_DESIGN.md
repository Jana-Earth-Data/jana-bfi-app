## 1. Executive Summary

All IFRS S2 B62 disclosures are **already computed** in `lib/regulatory/pcaf/` and attached to `PortfolioSummary`. None are currently displayed. This task adds UI components to surface them on the NFRS tab and in exports.

### 3.2 B62(a)(b) — Gross Exposure Matrix

**Display:** Industry × Asset Class table with 3 metrics per cell

**Data source:** `s.grossExposureMatrix`

**UI Component:**

```tsx
<Panel title="B62(a)(b) — Gross Exposure & Financed Emissions" collapsible defaultCollapsed>
  <p className="text-sm text-slate-300 mb-3">
    Disaggregation of gross exposure (funded carrying amount before loss allowance)
    and absolute gross financed emissions by industry and asset class per IFRS S2
    B62(a) and B62(b).
  </p>

  {s.grossExposureMatrix && s.grossExposureMatrix.length > 0 ? (
    <div className="overflow-x-auto">
      <table className="w-full text-sm">
        <thead>
          <tr className="border-b border-slate-700">
            <th className="text-left py-2">Industry (GICS)</th>
            <th className="text-left py-2">Asset Class</th>
            <th className="text-right py-2">Gross Exposure (USD)</th>
            <th className="text-right py-2">Gross Exposure (NPR)</th>
            <th className="text-right py-2">Financed Emissions (tCO₂e)</th>
            <th className="text-right py-2">Loan Count</th>
          </tr>
        </thead>
        <tbody>
          {s.grossExposureMatrix.map((row, i) => (
            <tr key={i} className="border-b border-slate-800">
              <td className="py-2">
                {row.gicsLabel ? (
                  <span title={`GICS ${row.gicsCode}`}>{row.gicsLabel}</span>
                ) : (
                  <span className="text-slate-500">{row.industry} (no GICS mapping)</span>
                )}
              </td>
              <td className="py-2 text-slate-300">{row.assetClass}</td>
              <td className="text-right py-2">${formatNumber(row.grossExposureUsd)}</td>
              <td className="text-right py-2">{formatNpr(row.grossExposureUsd * NPR_PER_USD)}</td>
              <td className="text-right py-2">{formatCo2e(row.attributedCo2eTonnes ?? 0)}</td>
              <td className="text-right py-2 text-slate-400">{row.loanCount}</td>
            </tr>
          ))}
        </tbody>
        <tfoot className="border-t-2 border-slate-600 font-semibold">
          <tr>
            <td colSpan={2} className="py-2">Total</td>
            <td className="text-right py-2">
              ${formatNumber(s.grossExposureMatrix.reduce((sum, r) => sum + r.grossExposureUsd, 0))}
            </td>
            <td className="text-right py-2">
              {formatNpr(s.grossExposureMatrix.reduce((sum, r) => sum + r.grossExposureUsd, 0) * NPR_PER_USD)}
            </td>
            <td className="text-right py-2">
              {formatCo2e(s.grossExposureMatrix.reduce((sum, r) => sum + (r.attributedCo2eTonnes ?? 0), 0))}
            </td>
            <td className="text-right py-2 text-slate-400">
              {s.grossExposureMatrix.reduce((sum, r) => sum + r.loanCount, 0)}
            </td>
          </tr>
        </tfoot>
      </table>
    </div>
  ) : (
    <p className="text-sm text-slate-500 italic">
      Gross exposure matrix not available (no in-scope attributions)
    </p>
  )}

  <InfoTip className="mt-2" title="IFRS S2 B62(a)(b)">
    Per IFRS S2 Climate-related Disclosures §B62(a) and (b), entity shall disclose
    absolute gross financed emissions disaggregated by industry (GICS 6-digit) and
    asset class, alongside the gross exposure (funded carrying amount before loss
    allowance) in presentation currency.
  </InfoTip>
</Panel>
```

**Key decisions:**
- Show BOTH USD and NPR (B62(b) requires presentation currency)
- GICS label displayed with code in title attribute
- Rows sorted by descending gross exposure (already done in `computeGrossExposureMatrix`)
- Table is scrollable horizontally on mobile

### 3.3 B62(c) — Coverage & Exclusions

**Display:** 3 key metrics + excluded asset types list

**Data source:** `s.grossExposureCoverage`

**UI Component:**

```tsx
<Panel title="B62(c) — Coverage & Exclusions" collapsible defaultCollapsed>
  <p className="text-sm text-slate-300 mb-3">
    Percentage of gross exposure included in financed-emissions calculation,
    with types of assets excluded named per IFRS S2 B62(c)(i)–(iii).
  </p>

  {s.grossExposureCoverage ? (
    <div className="grid gap-4">
      {/* Coverage percentage */}
      <div className="bg-slate-800/50 rounded p-3">
        <div className="text-sm text-slate-400 mb-1">Coverage Percentage</div>
        <div className="text-2xl font-semibold">
          {formatPercent(s.grossExposureCoverage.coveragePercent / 100)}
        </div>
        <div className="text-xs text-slate-500 mt-1">
          {formatNumber(s.grossExposureCoverage.includedLoanCount)} of {s.grossExposureCoverage.includedLoanCount + s.grossExposureCoverage.excludedLoanCount} loans included
          {' · '}
          ${formatNumber(s.grossExposureCoverage.includedGrossExposureUsd)} of ${formatNumber(s.grossExposureCoverage.totalGrossExposureUsd)} gross exposure
        </div>
      </div>

      {/* B62(c)(i) — Excluded asset types */}
      {s.grossExposureCoverage.excludedAssetTypes.length > 0 ? (
        <div className="bg-slate-800/50 rounded p-3">
          <div className="text-sm text-slate-400 mb-2">
            Excluded Asset Types <span className="text-slate-600">(B62(c)(i))</span>
          </div>
          <ul className="text-sm space-y-1">
            {s.grossExposureCoverage.excludedAssetTypes.map((type, i) => (
              <li key={i} className="text-slate-300">• {type}</li>
            ))}
          </ul>
        </div>
      ) : (
        <div className="bg-slate-800/50 rounded p-3">
          <div className="text-sm text-slate-400 mb-1">
            Excluded Asset Types <span className="text-slate-600">(B62(c)(i))</span>
          </div>
          <p className="text-sm text-emerald-400">None — all asset types included</p>
        </div>
      )}

      {/* B62(c)(ii) — Risk mitigants */}
      <div className="bg-slate-800/50 rounded p-3">
        <div className="text-sm text-slate-400 mb-1">
          Risk Mitigants <span className="text-slate-600">(B62(c)(ii))</span>
        </div>
        <p className="text-sm text-slate-300">
          {s.grossExposureCoverage.riskMitigantsExcluded
            ? `Risk mitigants (collateral, guarantees) are NOT excluded from gross exposure. Total collateral value: $${formatNumber(s.grossExposureCoverage.totalRiskMitigantValueUsd)}.`
            : "No risk mitigants present in the portfolio."
          }
        </p>
        <p className="text-xs text-slate-500 mt-1">
          Per B62(c)(ii), gross exposure reflects the FULL funded amount before deducting
          collateral or guarantees. Risk mitigants protect the bank's downside but do not
          change the carbon intensity of financed activities.
        </p>
      </div>

      {/* B62(c)(iii) — Undrawn commitments placeholder */}
      <div className="bg-slate-800/50 rounded p-3">
        <div className="text-sm text-slate-400 mb-1">
          Undrawn Commitments <span className="text-slate-600">(B62(c)(iii))</span>
        </div>
        <p className="text-sm text-slate-500 italic">
          Undrawn commitment disclosure not yet implemented (N1.4)
        </p>
      </div>
    </div>
  ) : (
    <p className="text-sm text-slate-500 italic">
      Coverage disclosure not available
    </p>
  )}
</Panel>
```

**Key decisions:**
- Coverage displayed as prominent percentage
- Excluded asset types shown as bulleted list (empty state = "None")
- Risk mitigant disclosure clarifies the N1.1 fix (NOT subtracted)
- Undrawn commitments shown as placeholder (N1.4 task still pending)

## 4. Component Architecture

### 4.1 New Components to Create

**Location:** `components/bfi/shared/b62-disclosures/`

```
b62-disclosures/
├── gross-exposure-matrix.tsx       (B62(a)(b) table)
├── coverage-disclosure.tsx          (B62(c) coverage cards)
├── methodology-disclosure.tsx       (B62(d) method tables)
├── data-extent-disclosure.tsx       (B55-B56 cards)
├── consolidation-disclosure.tsx     (B27 simple card)
└── index.ts                         (barrel export)
```

**Benefits:**
- Each disclosure is a self-contained, testable component
- Can be reused in exports (PDF/Excel rendering)
- Easy to unit test in isolation
- Keeps nfrs-tab.tsx clean (just imports + composes)

### 4.2 Shared Primitives Needed

Add to `components/bfi/shared/primitives.tsx`:

```tsx
export function CollapsiblePanel({
  title,
  defaultCollapsed = true,
  children
}: {
  title: string;
  defaultCollapsed?: boolean;
  children: React.ReactNode;
}) {
  const [collapsed, setCollapsed] = useState(defaultCollapsed);

  return (
    <div className="bg-slate-900/50 border border-slate-800 rounded-lg">
      <button
        className="w-full flex items-center justify-between p-4 hover:bg-slate-800/30 transition"
        onClick={() => setCollapsed(!collapsed)}
      >
        <h3 className="text-lg font-semibold">{title}</h3>
        <span className="text-slate-500">{collapsed ? "▶" : "▼"}</span>
      </button>
      {!collapsed && (
        <div className="p-4 pt-0 border-t border-slate-800">
          {children}
        </div>
      )}
    </div>
  );
}
```

**Also add:**
- `formatNumber(n: number)` - thousands separator (if not already exists)
- Ensure `formatCo2e`, `formatNpr`, `formatPercent` handle edge cases (0, undefined)

## 8. Risks & Mitigations

|------|------------|--------|------------|
| Gross exposure matrix too large for UI (100+ rows) | Medium | High | Paginate table (10 rows per page) or add search filter |
| GICS labels too long, break table layout | Low | Medium | Truncate with ellipsis + tooltip on hover |
| Methodology disclosure data undefined (old attributions) | Medium | Medium | Show "Not available" with explanation (backward compat) |
| Export file size too large (10K+ loans) | Low | Low | Excel handles 1M rows; PDF truncates to top N |
